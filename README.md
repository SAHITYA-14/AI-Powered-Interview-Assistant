# AI-Powered Conversational Interview Assistant

An AI-assisted interview practice platform that helps users practice answering questions, improve their communication, and prepare for interviews.

## Features

- **Multiple Topics:** Self-Introduction, Generative AI, Python, English, HTML, and CSS.
- **Adaptive Follow-Up Questions:** Questions can build on previous responses.
- **Voice Interaction:** Voice-based question-and-answer practice.
- **Constructive Feedback:** Feedback and examples to help users improve their responses.

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/SAHITYA-14/AI-Powered-Interview-Assistant.git
   ```

2. Open the project folder in VS Code.
3. Install the Python dependencies required by the backend.
4. Configure any required API keys using environment variables.
5. Start the Flask backend and open the frontend using the method configured in your project.

## Security

Never commit API keys, passwords, or other secrets to GitHub. Keep them in a local `.env` file.
